* PageRank-based graph intelligence

**Built with:**

### 📚 Novel Backstory Checker

A RAG-based text classification system developed for **KDSH 2026 Track A**.

* Designed around a 100K-novel corpus
* Long-context ingestion and retrieval pipeline
* Chunking → embedding → top-k retrieval
* TF-IDF + retrieved-context features
* HistGradientBoosting classification

**Built with:**
`Python` `Pathway` `scikit-learn` `sentence-transformers`
